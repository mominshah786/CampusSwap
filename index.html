Why CampusSwap?

Safer, closer, and built just for campus life.

Unlike generic marketplaces, CampusSwap focuses on verified students, real campus locations, and the types of items students actually trade.

✅

Student-only environment

Restrict access to users with a valid campus email to keep the marketplace focused and reduce scam risk.

📚

Made for student items

Textbooks, lab calculators, mini fridges, dorm furniture, lab coats, club merch — everything campus-related in one place.

📍

Local meet-up spots

Meet on campus at the library, student center, or residence hall lobbies for convenient and safe item exchanges.

🧠

Designed with GenAI

This prototype was architected and implemented with the help of GenAI tools, then refined and tested by a CS2 student.

How it works

From idea to working prototype in one week.

For this CS2 project, CampusSwap was implemented as a front-end web app with in-browser storage. The same flow could later plug into a full backend and mobile app.

1
Define the core user actions
List the must-have features: create a listing, browse items, search/filter, and keep everything lightweight and private.
2
Design a clean UI experience
Use a modern layout, card-based listings, and distinct sections for features, story, and the live app, similar to real startup sites.
3
Implement the live marketplace
Use HTML, CSS, and vanilla JavaScript to manage listings and persist data using localStorage inside the browser.
Roadmap

From prototype to real startup.

This CS2 project focuses on the front-end experience and GenAI-assisted development, but it’s designed with a clear upgrade path to a full production app.

Next technical steps

  • User accounts with real student login (OAuth + .edu verification).
  • Backend API to store listings in a database instead of localStorage.
  • Real-time messaging between buyer and seller with read receipts.
  • Rating & reputation system to track reliable buyers/sellers.
  • Mobile app version (React Native / Flutter) using the same API.

What’s next for the product

  • Partner with campus bookstores and clubs for official “verified” drops.
  • Offer campus-safe meet-up spots and safety tips in-app.
  • Introduce AI to auto-write listings and detect scammy posts.
  • Allow campus orgs to run event ticket resales and merch swaps.
